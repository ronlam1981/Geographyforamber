# 地理研習室

初二地理小測：人教版八上第一章「從世界看中國」與第二章第一節「地形」。

- 4章重點教材、97道原創文字題（選擇／填空／簡答）
- 37個地圖填空位置，接受常見繁簡字
- 25分鐘模擬卷，倒數收卷、重整續答、人工／自評簡答
- 錯題重練、答對兩次的掌握進度、本機學生記錄、匯出成績圖和備份
- 家長本機操作鎖、手動新增及JSON匯入題庫

## 使用

GitHub Pages以main分支根目錄發布。純靜態HTML、CSS與JS，無建置及付費API。記錄存於localStorage，未設雲端同步。家長PIN只作本機操作鎖，並非伺服器驗證。

## 教材與來源

依家長提供的測驗範圍、掃描工作紙編寫；未公開學生姓名、班級、學號或原附件。人口數字分課堂約數、2020普查範圍與2025延伸資料；題目注明口徑。地圖輪廓依Natural Earth（公共領域）簡化，山脈為教學走向示意，並非正式疆界或精確測繪。

網站「資料來源」列中國政府網／中聯辦轉載地形及版圖、國家統計局人口普查與2025人口資料。

## 新增題庫

家長在學習記錄頁匯入JSON題目陣列。每題須有chapter（territory/population/ethnic/terrain）、type（mc/fill/short）、q、answer、explanation。選擇題另需4個options，answer為0至3；簡答可另加points要點陣列；填空可加aliases同義寫法陣列。

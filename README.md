# 地理研習室

初二地理小測：人教版八上第一章「從世界看中國」與第二章第一節「地形」。

- 4章重點教材、97道原創文字題（選擇／填空／簡答）
- 37個地圖填空位置，接受常見繁簡字
- 25分鐘模擬卷，倒數收卷、重整續答、人工／自評簡答
- 錯題重練、答對兩次的掌握進度、本機學生記錄、匯出成績圖和備份
- 家長本機操作鎖、手動新增及JSON匯入題庫

## 使用

GitHub Pages以main分支根目錄發布。純靜態HTML、CSS與JS，無建置及付費API。記錄存於localStorage，未設雲端同步。家長PIN只作本機操作鎖，並非伺服器驗證。

## 教材與來源

依家長提供的測驗範圍、掃描工作紙編寫；未公開學生姓名、班級、學號或原附件。人口數字分課堂約數、2020普查範圍與2025延伸資料；題目注明口徑。地圖輪廓依Natural Earth（公共領域）簡化，山脈為教學走向示意，並非正式疆界或精確測繪。

網站「資料來源」列中國政府網／中聯辦轉載地形及版圖、國家統計局人口普查與2025人口資料。

## 新增題庫

家長在學習記錄頁匯入JSON題目陣列。每題須有chapter（territory/population/ethnic/terrain）、type（mc/fill/short）、q、answer、explanation。選擇題另需4個options，answer為0至3；簡答可另加points要點陣列；填空可加aliases同義寫法陣列。

## 音效及動畫

音效初次使用預設開啟；可靜音及調整音量，設定保存在本機。首次點擊後啟用瀏覽器音效。提供答對音階、答錯提示、點擊與地圖聚焦音、回合完成／滿分旋律，配合彩花、震動、脈衝高亮及提示。遵從系統減少動態效果設定；未加入背景音樂、外部音效下載或追蹤服務。

## 完整學習流程及分卷題庫（2026-10-14）

- 重點複習可逐項勾選完成；每位學生及每個題庫獨立保存，修改重點內容後需重新確認。
- 每回合最多10道不同文字題；尚未連續答對兩次的題目會放回回合末尾，直至掌握，或學生主動結束。答題後顯示标准及廣東話解析，點「明白了」繼續。
- 學習及測驗均重新排列選擇題選項，保持正確答案對應；測驗期間不呈現答對音效或答案提示。
- 保留25分鐘混合卷，另有最多40題的選擇專項模式。新題庫按實際題型與題量組卷，動態折算100分，不補造題目。
- 錯題可逐一回顧，對照已選答案、正確答案、解析和地圖位置。
- 記錄登入／離開、各卷活動開始及結束、頁面可見的有效時間、回合次數及分數。中斷時標示最後保存時間；舊記錄不補造未曾計時的時長。
- 既有97題及37個標註歸入「初二上冊｜10月14日小測」。另備上冊其他測驗及下冊空白題庫，清楚標為待加題；不假造未提供教材。

### 家長更新新考試內容

家長PIN仍為0000。到題庫管理建立新考試卷，加入／修改題目與重點，或匯入JSON／CSV。匯入前顯示題數、重點、地圖位置及更新影響，提供追加、按ID更新、建立另一個新題庫三種方式。

- 原題目ID保持不變，未修改的題目進度保留；題幹、答案或評分條件改變時重設該題掌握。不同題庫的題目ID會加題庫前綴。
- 支援本平台JSON格式，及說明書的q／opts（t、c）／exp格式。CSV欄位可用question,A,B,C,D,answer,explanation，或q,type,chapter,answer,explanation；選擇答案可用A-D，JSON亦可用0-3。
- JSON可另有lessons（id/name/cards）、maps（id/name/kind/lon/lat）及source。地圖標註限於目前中國位置底圖的範圍。
- 可下載匯入範例、匯出單卷題庫及完整備份。新加入内容僅保存在本機；要公開網站對所有人同步更新，需將新教材交給維護者提交網站更新。
- PDF及掃描教材須先整理為題庫，不把PDF文字提取誤稱為掃描辨識。
